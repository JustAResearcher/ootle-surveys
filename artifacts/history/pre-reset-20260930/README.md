# Historical verification

These files record the pre-reset Esmeralda deployment and September 21 verification.
Ootle 0.42 reset the public testnet on September 30. The addresses and transaction
IDs here are historical evidence, not live components, available balances or current
payment confirmations. The old compiled artifact remains in Git history.

Use the deployment and verification files in the top-level `artifacts/` directory
for the replacement deployment.
